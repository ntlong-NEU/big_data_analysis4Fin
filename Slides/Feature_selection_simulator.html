The Univariate Trap

The XOR Gate Blind Spot

Why individual filter metrics fail on joint interactions.

Score(X1 → y): r = 0.00 | MI = 0.00 nats
Score(X2 → y): r = 0.00 | MI = 0.00 nats
Fatal Flaw: Univariate filters evaluate each feature independently. In XOR, marginal distributions for class 0 and class 1 overlap 100%, causing the filter to discard both variables despite 100% joint separability!

Search Strategy Complexity Fits for P=30 Feasibility

Greedy Trade-Off: While Exhaustive search is guaranteed to find the globally optimal subset, its exponential complexity makes it physically impossible beyond P ≥ 40. RFE and SFS make locally optimal greedy choices, finishing in polynomial time.

L1 Lasso (Diamond) vs. L2 Ridge (Circle) Optimization Geometry

The Overfitting Trap

Tree MDI High-Cardinality Trap vs. Permutation Importance

Witness how Mean Decrease in Impurity (MDI) deceptively ranks random ID noise as #1, and how Permutation Importance unmasks it.

The Flaw: High-cardinality variables offer thousands of arbitrary candidate split thresholds. Greedy trees exploit these to memorize the training set, falsely inflating MDI.

The Remedy: By breaking the link between UUID and the target on unseen holdout data, the validation score does not drop (ΔScore ≤ 0), exposing the noise variable!

❌ Flawed Workflow: Pre-Selection Leakage Fake CV: 86.4%

2. Perform 5-Fold Cross-Validation on selected 5 features.
